# Khalil Etana Portfolio

A responsive Next.js App Router portfolio mockup built with React, Tailwind CSS, and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Notes

- The layout is inspired by the minimalist, narrative, project-first structure of jonrodz.com.
- Supplied names, project titles, claims, tools, roles, and institutional information are preserved.
- No testimonials, client logos, metrics, project years, dates, or unsupported business details were invented.
- The project visual areas use CSS/inline icon treatments rather than invented project photography.
- The email action intentionally has no destination because no email address was supplied. Replace `href="mailto:"` in `app/page.tsx` with the real address when available.
